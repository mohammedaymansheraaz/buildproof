# BuildProof Logo Brief

## Product

BuildProof is an AI application auditing platform. It reviews a web app before release from three professional perspectives:

- Application Experience & Quality: UI behavior, user journeys, accessibility, broken interactions.
- Engineering Performance & Infrastructure: APIs, backend behavior, databases, cloud readiness, scalability, deployment risk.
- Security & Reliability Intelligence: vulnerabilities, authentication, authorization, data protection, reliability risks.

The brand should communicate one idea clearly: BuildProof gives founders and teams evidence that their app is ready before users or attackers find the weak points.

## Logo Concept

Create a premium technical logo that combines:

- A proof/check signal for release confidence.
- Three audit lenses or chambers for the three expert review categories.
- Subtle engineering grid/circuit geometry.
- A restrained security shield contour.
- A compact `B` silhouette so the mark can work as an app icon.

The logo should feel like an intelligent audit engine, not a generic cybersecurity badge.

## Primary Tagline Options

1. From broken flows to hidden breaches, get proof before you ship.
2. Prove it works. Prove it's secure. Prove it's ready.
3. Find what breaks, leaks, and slows down before release.

## Image Generation Prompt

Use case: logo-brand
Asset type: premium app logo concept for an AI application auditing platform
Primary request: Create a polished square logo for an app named "BuildProof". The logo should communicate an AI engineering audit platform that checks application experience, engineering infrastructure, and security reliability before release.
Scene/backdrop: clean dark void background, centered logo, no mockup, no device, no large cast shadows.
Subject: a compact vector-friendly emblem: a stylized letter B formed from three interlocking audit chambers or lenses. The top chamber suggests user experience and interface quality with a small flow-node/check motif. The middle chamber suggests engineering systems with precise circuit/grid line geometry. The lower chamber suggests security with a subtle shield/lock contour. The whole mark should feel like a proof seal and release-readiness scanner, not a generic cybersecurity logo.
Style/medium: premium modern vector-logo aesthetic rendered as high-resolution bitmap; Apple-level restraint, technical, crisp, sophisticated, not cartoonish.
Composition/framing: centered square composition with generous padding. Include a clean wordmark "BuildProof" beneath the emblem, spelled exactly, using a modern geometric sans type style. The emblem must also work alone as an app icon.
Lighting/mood: refined glass-metal depth, subtle dimensional bevels, precise highlights, premium dark interface mood.
Color palette: deep void background, ink-white text, restrained cyan signal accent, tiny warm amber proof highlight, semantic green check used sparingly. Avoid dominant purple, neon cyberpunk, rainbow gradients, and noisy glow.
Materials/textures: glassy translucent layers, brushed graphite edges, thin luminous scan lines, crisp vector edges.
Text verbatim: "BuildProof"
Constraints: exact spelling if text is included; logo must be readable at app-icon size; show the three audit perspectives through simple symbolic geometry; premium startup brand identity; no complex illustration.
Avoid: cluttered badges, skulls, hacker stereotypes, human characters, generic shield-only mark, generic robot face, exaggerated neon, 3D mascot, stock logo look, watermark, fake UI screenshots.
